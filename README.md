# 🚨 ResQNow — Emergency SOS System

ResQNow is a web-based emergency assistance application designed to help users request help during critical situations. The project focuses on making emergency alerting more accessible through a simple interface and a backend that manages user information and emergency-related data.

## ✨ Features

- 🚨 SOS emergency alert interface
- 📩 Emergency notifications to designated contacts
- 👤 User information management
- 🗄️ MySQL database integration
- 🖥️ Responsive and user-friendly interface
- ⚡ Flask backend for application logic
- 📱 Accessible interface for different screen sizes

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- JavaScript

## ⚙️ How It Works

1. The user accesses the ResQNow application.
2. The user initiates an SOS request.
3. The backend processes the emergency request.
4. The system uses the configured notification mechanism to alert designated contacts.
5. Emergency-related information is managed by the application.

## 🚀 Getting Started

### Prerequisites

- Python installed
- MySQL Server installed and running
- pip package manager

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/resqnow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd resqnow
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

   Windows PowerShell:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

4. Install the project dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Configure your MySQL database and environment variables.

6. Start the Flask application using the project's entry-point file:

   ```bash
   python app.py
   ```

7. Open the local URL displayed in the terminal.

## 🔐 Configuration

Store database credentials and notification-service credentials in environment variables. Do not commit passwords, API keys, or other secrets to GitHub.
